# Анализ рынка электромобилей (Washington State EV Population)

Разведочный анализ данных о зарегистрированных электромобилях в штате Вашингтон: очистка данных, работа с SQLite и визуализация ключевых показателей рынка EV.

## Датасет

Данные взяты с портала [Data.gov](https://catalog.data.gov/dataset/electric-vehicle-population-data?from_hint=eyJzb3J0IjoicG9wdWxhcml0eSJ9) — реестр электромобилей, зарегистрированных через Washington State Department of Licensing (DOL).

Датасет содержит записи о регистрациях именно через DOL штата Вашингтон, а не общенациональную статистику по США. Подавляющее большинство записей относится к владельцам из WA. Поле `state` для других штатов встречается редко (например, если владелец переехал). Поэтому сравнение "штатов США по количеству EV" в этом анализе отражает не реальное распределение электромобилей по стране, а особенность источника данных — это учтено в анализе.

## Задачи анализа

- Очистить и подготовить данные к анализу (пропуски, дубликаты, некорректные записи);
- Изучить распределение электромобилей внутри выборки (штаты, города Вашингтона);
- Проанализировать распределение запаса хода на электротяге (`electric_range`);
- Определить самых популярных производителей;
- Изучить соотношение полностью электрических и гибридных автомобилей.

## Стек технологий

- **Python 3** — язык анализа
- **Pandas** — загрузка и первичная обработка данных
- **SQLite** — очистка, агрегация и выборки через SQL
- **Matplotlib** — визуализация

## Основные выводы

1. Внутри выборки подавляющее большинство электромобилей зарегистрировано в штате Вашингтон — это ожидаемо, так как источник данных сам ограничен регистрациями через WA DOL, а не отражает реальное соотношение EV между штатами США.
2. Среди городов Вашингтона лидирует Сиэтл — крупнейший город штата с наибольшей плотностью инфраструктуры для электромобилей.
3. Распределение запаса хода (`electric_range`) имеет два локальных максимума: в районе 30–40 миль (гибриды и более старые модели) и 200–220 миль (современные полностью электрические автомобили).
4. Tesla занимает наибольшую долю рынка среди производителей (~41% в выборке).
5. Около 80% зарегистрированных электромобилей — полностью электрические (BEV), около 20% — гибриды (PHEV).

## Ограничения анализа

- Данные ограничены регистрациями через Washington State DOL — выводы о "рынке США" носят иллюстративный характер и не могут быть перенесены на всю страну без дополнительной проверки на национальных данных.
- Пропуски в поле `electric_range` для отдельных новых моделей (например, Lamborghini Revuelto/Temerario) заполнены значением 0 как индикатор отсутствия данных, а не реального нулевого запаса хода; такие строки исключены из соответствующих графиков.
